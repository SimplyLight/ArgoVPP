## 🎯 OBJECTIF GLOBAL

Calculer la polaire de vitesse d'avance V_B(TWA) pour tous les caps (0°-360°) 
en utilisant un modèle aérodynamique hybride qui combine:

- MODÈLE AILE: Pour les caps < 160° (remontée/travers)
  → Portance + traînée orientées (haute efficacité)
  → Force = L·sin(β) - D·cos(β)

- MODÈLE SPY: Pour les caps > 180° (vent arrière)
  → Traînée pure (parachute)
  → Force = D

- TRANSITION LISSE: 160°-180°
  → Interpolation progressive AILE → SPY
  → Force = (1-t)·F_aile + t·F_spy

================================================================================
## 📐 FORMULES MATHÉMATIQUES ESSENTIELLES

### PHASE 1: CALCUL DU VENT APPARENT
─────────────────────────────────────

Fonction: calc_apparent_wind(V_TW, V_B, TWA_deg)

Composition vectorielle:
  V_aw = V_tw + V_bw (vent réel + vent créé par bateau)

Composantes cartésiennes (frame bateau):
  V_tw,x = V_tw · sin(TWA)         [transversal]
  V_tw,y = -V_tw · cos(TWA)         [longitudinal]
  V_aw,x = V_tw · sin(TWA)          [apparent transversal]
  V_aw,y = -V_tw · cos(TWA) + V_B   [apparent longitudinal]

Amplitude et angle:
  V_aw = √(V_aw,x² + V_aw,y²)
  β_aw = arctan2(V_aw,x / -V_aw,y)  [angle vent apparent]

EXEMPLE (V_TW=10 m/s, V_B=5 m/s, TWA=180°):
  V_aw,x = 10·sin(180°) = 0
  V_aw,y = -10·cos(180°) + 5 = 10 + 5 = 15 m/s
  V_aw = 15 m/s, β_aw = 0° (vent droit devant)

================================================================================
### PHASE 2: FORCES AÉRODYNAMIQUES
──────────────────────────────────

Fonction: calc_aero_forces_sail(V_AW, beta_AW_deg, alpha_trim, polar_tables, ...)

2.1 - Nombre de Reynolds (pour interpolation polaire):
  Re = (ρ_air · V_aw · c_moy) / μ_air
     = (1.225 · V_aw · c_moy) / (1.81e-5)

  Paramètres fixes:
    ρ_air = 1.225 kg/m³ (densité air)
    μ_air = 1.81e-5 Pa·s (viscosité air)
    c_moy = corde moyenne voile (m) — paramètre entrée

  Détermine à quel Reynolds lire les coefficients polaires NACA

2.2 - Coefficients aérodynamiques:
  α_eff = β_aw - α_trim  [angle d'attaque effectif]
  C_l = f_interp(Re, α_eff)  [coefficient portance — table NACA]
  C_d = g_interp(Re, α_eff)  [coefficient traînée — table NACA]

  Gestion angles hors limites:
    - Si α_eff < α_min: utiliser -α_eff avec C_l opposé (symétrie)
    - Si α_eff > α_max: clipper à α_max

2.3 - Forces liftées:
  q_dyn = 0.5 · ρ_air · V_aw²  [pression dynamique]
  L_aero = C_l · q_dyn · A_sail  [portance (N)]
  D_aero = C_d · q_dyn · A_sail  [traînée (N)]

  Paramètres:
    A_sail = surface voile projetée (m²)

2.4 - MODÈLE HYBRIDE AILE/SPY (cœur de la cellule):

ZONE 1: AILE (TWA < 160°)
─────────────────────────
  F_prop = L_aero · sin(β_aw) - D_aero · cos(β_aw)

  Interprétation:
    • Portance L perpendiculaire au vent
    • Composante utile: L·sin(β) = projection selon axe bateau
    • Traînée D freine: -D·cos(β) = opposition au mouvement
    • EFFICACE car β ≠ petit (portance contribue vraiment)

ZONE 2: TRANSITION (160° ≤ TWA ≤ 180°)
───────────────────────────────────────
  t = (TWA - 160°) / 20°  [paramètre: 0 à 1]
  
  F_aile = L_aero · sin(β_aw) - D_aero · cos(β_aw)
  F_spy = D_aero
  
  F_prop = (1 - t) · F_aile + t · F_spy
         = (1 - t) · [L·sin(β) - D·cos(β)] + t · D

  Justification physique:
    → En vent arrière (β → 0°): sin(β) → 0 (portance inefficace)
    → Interpolation modélise transition progressive
    → Élimine discontinuités numériques

ZONE 3: SPY (TWA > 180°)
────────────────────────
  F_prop = D_aero

  Interprétation:
    • Voile repositionnée en "parachute"
    • Toute la traînée devient propulsive
    • Portance perpendiculaire → inutile
    • OPTIMAL pour vent arrière pur

================================================================================
### PHASE 3: RÉSISTANCE HYDRODYNAMIQUE
──────────────────────────────────────

Fonction: calc_hydro_drag(V_B, S_wetted, CR_friction, Rcoque_coeff, rho_water)

Formule générale:
  R_hydro = C_R_total · (1/2) · ρ_water · V_B² · S_wetted

où:
  C_R_total = CR_friction + Rcoque_coeff

  Paramètres:
    ρ_water = 1025 kg/m³ (eau de mer)
    CR_friction ≈ 0.003 (coefficient friction plaque plate)
    Rcoque_coeff ≈ 0.002 (résistance appendices: quille, safran, etc.)
    
    ⚠️ Rcoque_coeff est le PARAMÈTRE CLÉ D'AJUSTEMENT
       Augmenter → plus de traînée → V_B plus faible
       Diminuer → moins de traînée → V_B plus élevée

Exemple (V_B = 5 m/s, S_wetted = 0.42 m², C_R = 0.005):
  q_water = 0.5 × 1025 × 5² = 12812.5 Pa
  R_hydro = 0.005 × 12812.5 × 0.42 = 26.9 N

================================================================================
### PHASE 4: SOLVEUR D'ÉQUILIBRE - DICHOTOMIE
──────────────────────────────────────────────

Fonction: solve_equilibrium(V_TW, TWA, polar_tables, ...)

Objectif: Résoudre F_prop(V_B) = R_hydro(V_B) pour trouver V_B

Pourquoi non-linéaire?
  • F_prop dépend de V_B via V_aw (qui change)
  • R_hydro dépend de V_B au carré
  → Pas de solution analytique → besoin solveur numérique

Algorithme: BISECTION (dichotomie)

Initialisation:
  V_B_min = max(0.1, 0.05 × V_TW)      [limite basse]
  V_B_max = 2.0 × V_TW                 [limite initiale]

Vérification borne supérieure:
  Si F_prop(V_B_max) > R_hydro(V_B_max)
    → Voile plus forte que traînée
    → Bateau peut aller plus vite
    → Étendre: V_B_max = 3.0 × V_TW

Boucle itérative (max 50 itérations):
  V_B_mid = (V_B_min + V_B_max) / 2
  
  error = F_prop(V_B_mid) - R_hydro(V_B_mid)
  
  Critère convergence:
    Si |error| < 0.5 N: ✓ CONVERGÉ (trouvé V_B)
    
  Réduction intervalle:
    Si error > 0: force trop forte
      → V_B_min = V_B_mid (augmenter min)
      
    Si error < 0: force trop faible
      → V_B_max = V_B_mid (diminuer max)

Résultat: V_B où F_prop = R_hydro (précision ±0.5 N)

Exemple d'itération:
  Iter 1: V_B_mid = 5.0 m/s → error = +50 N  → V_B_min = 5.0
  Iter 2: V_B_mid = 7.5 m/s → error = -10 N → V_B_max = 7.5
  Iter 3: V_B_mid = 6.25 m/s → error = +2 N → V_B_min = 6.25
  Iter 4: V_B_mid = 6.875 m/s → error = -1 N → V_B_max = 6.875
  ...
  Iter N: |error| < 0.5 ✓ CONVERGENCE

### PHASE 5: POLAIRE COMPLÈTE
─────────────────────────────

Fonction: compute_polaire(V_TW, profile_file, alpha_trim, A_sail, c_moy, ...)

Pseudo-code:

  For chaque cap TWA dans [0°, 2°, 4°, ..., 358°]:  # 180 points
    
    1. Appeler solve_equilibrium(V_TW, TWA, ...)
       → Retourne V_B(TWA) et tous les intermédiaires
    
    2. Calculer VMG (Velocity Made Good):
       VMG = V_B × |cos(TWA)|
       [Vitesse utile en direction but optimal]
    
    3. Stocker ligne dans DataFrame:
       {TWA, V_B, V_AW, Re, Cl, Cd, F_prop, R_hydro, VMG, model, converged}

  Résultat: DataFrame 180 lignes × 13 colonnes

Temps calcul: ~1 seconde pour 180 points

## 💡 NOTES IMPORTANTES

1. SYMÉTRIE BÂBORD/TRIBORD:
   • TWA ∈ [180°-360°] traité par réflexion de TWA ∈ [0°-180°]
   • Physiquement, c'est correct (bateau symétrique)

2. GESTION ANGLES HORS LIMITES:
   • Profils NACA limités (ex: NACA0012 : α ∈ [-15°, +15°])
   • Si α_eff dépasse: clipper ou utiliser symétrie

3. MODÈLE SPY PHYSIQUEMENT JUSTIFIÉ:
   • En vent arrière (β → 0°): portance perpendiculaire
   • sin(0°) = 0 → contribution portance → 0
   • Traînée est tout ce qui reste → modèle SPY correct

4. TRANSITION LISSE (160-180°):
   • Évite discontinuités numériques
   • Modélise repositionnement voile progressif
   • Interpolation linéaire simple mais efficace

5. DICHOTOMIE ROBUSTE:
   • Converge même si F_prop ou R_hydro complexes
   • Garantit solution exacte (pas approximation)
   • Max 50 itérations (~log₂ intervalle initial)

6. VITESSE MAXIMALE:
   • Généralement entre 100°-140° (travers arrière)
   • Zone AILE → portance = 90% de l'efficacité
   • Correspond à "reaching" en voile (optimal)

## 📈 DIAGRAMME DE FLUX COMPLET

INPUT:
  ├─ V_TW (vent réel)
  ├─ α_trim (angle de trim voile)
  ├─ A_sail (surface voile)
  ├─ c_moy (corde moyenne)
  ├─ S_wetted (surface mouillée)
  ├─ CR_friction, Rcoque_coeff (résistances)
  └─ n_twa = 180 (résolution polaire)

PHASE 1 (Vent apparent):
  calc_apparent_wind(V_TW, V_B, TWA)
  → V_aw, β_aw

PHASE 2 (Forces aérodynamiques):
  calc_aero_forces_sail(V_aw, β_aw, α_trim, polaires)
  → L_aero, D_aero
  → F_prop (modèle hybride AILE/SPY)

PHASE 3 (Résistance hydro):
  calc_hydro_drag(V_B, CR, ρ, S_wetted)
  → R_hydro

PHASE 4 (Équilibre):
  solve_equilibrium()
  Résoudre: F_prop(V_B) = R_hydro(V_B)
  → V_B (dichotomie, max 50 iter)

PHASE 5 (Polaire):
  compute_polaire()
  Boucle sur 180 × TWA
  → DataFrame complet

VISUALISATION:
  plot_polaire_complete()
  ├─ Rose des vents (V_B polaire)
  ├─ V_B vs TWA (zones coloriées)
  ├─ VMG vs TWA
  ├─ Distribution modèles (camembert)
  └─ Forces aérodynamiques vs hydrodynamiques

OUTPUT:
  DataFrame `df_polaire` (180 lignes)
  avec colonnes: [TWA, V_B, V_AW, Re, Cl, Cd, F_prop, R_hydro, VMG, model, converged]
